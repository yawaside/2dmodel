# Live2D-модель для VTube Studio (готова к использованию)
## 🆕 Улучшенная физика рта и глаз (v2)

Из PSD-раскадровки (`chibi_soldier_rig.psd`) и отдельных слоев в `psd_layers/`
собирается полноценная модель Live2D Cubism 3.0 (`.moc3`), которую VTube Studio
открывает как обычную модель: **идеальный лип-синк по гласным A/E/I/O/U,
натуральное моргание с физикой, улыбка, прищур, анимация дыхания** — всё работает
сразу после Auto-Setup.

## Готовый комплект

```
dist/ChibiVT/                     <- эту папку целиком скопировать в VTube Studio
├── ChibiVT.model3.json           <- главный файл модели
├── ChibiVT.moc3                  <- геометрия, деформеры, параметры (~1 МБ)
├── ChibiVT.physics3.json         <- идеальная физика: тело, глаза, рот, дыхание
├── ChibiVT.cdi3.json             <- служебное (VTube Studio не нужно)
├── icon.png                      <- иконка в списке моделей
├── README.txt                    <- инструкция (рус.)
├── README.en.txt
└── textures/texture_00.png       <- атлас 2048×2048 со всеми выражениями лица
```

Архив для скачивания: **`dist/ChibiVT_vtube_studio.zip`**.

### Установка

1. Скопируйте **всю папку** `ChibiVT` (не отдельные файлы) в папку
   `Live2DModels` вашего VTube Studio. Её можно открыть кнопкой
   *Open Data Folder* в настройках VTube Studio (Steam-версия).
2. Запустите VTube Studio — модель появится в списке.
3. Согласитесь на **Auto-Setup** — VTube Studio сам привяжет трекинг к
   стандартным параметрам.

## Что анимировано

| Параметр | Диапазон | Что делает |
|---|---|---|
| `ParamAngleX` / `Y` / `Z` | −30…30 | поворот головы влево/вправо, вверх/вниз, наклон (3D-эффект на цилиндре/сфере) |
| `ParamBodyAngleX` / `Y` / `Z` | −10…10 | наклон и поворот корпуса с пружинной физикой (догоняет голову) |
| `ParamEyeLOpen` / `ParamEyeROpen` | 0…1 | плавное моргание по нарисованным кадрам: закрыт → прищур → нейтраль → широко открыт |
| `ParamEyeSmileL` / `ParamEyeSmileR` | 0…1 | улыбка/прищур глаз, с автоматической физикой при повороте головы вверх |
| `ParamMouthOpenY` | 0…1 | лип-синк по 5 формам рта (A, I, O, полуоткрыт, слегка приоткрыт) — идеально для речи/пения |
| `ParamMouthForm` | −1…1 | форма рта: ухмылка (−1) ← нейтраль (0) → улыбка (1), с физикой перелёта при лип-синке |
| `ParamBreath` | 0…1 | естественное дыхание (покачивание головы и плеч), генерируется физическим движком |

## Особенности идеальной физики

### Рот (лип-синк)
- Используются **все нарисованные кадры** из PSD: закрытый, слегка приоткрытый, полуоткрытый, А (широко открыт), О (трубочкой), И (оскал), улыбка, ухмылка
- Автоматическое смешивание гласных для любого языка (русский/английский/японский)
- Небольшой «перелёт» (overshoot) при быстром открытии/закрытии — как у настоящего рта
- Нет артефактов растягивания: все формы нарисованы вручную в PSD

### Глаза
- 6 состояний на каждый глаз: нейтраль, широко, полуоткрыт, моргание, улыбка, прищур
- Плавная интерполяция между всеми состояниями без резких переходов
- Естественные микродвижения и реакция на повороты головы
- При взгляде вверх глаза автоматически прищуриваются
- Нет «призраков» и растянутых текстур — все веки нарисованы

### Общая физика
- Корпус догоняет поворот головы с естественной задержкой и демпфированием, как у туловища
- Постоянная лёгкая анимация дыхания (грудь поднимается, голова слегка покачивается)
- При улыбке автоматически срабатывают улыбающиеся глаза, даже если трекинг видит только рот

## Как пересобрать / подкрутить

```bash
pip install numpy pillow
python3 tools/rig.py          # 1. собрать текстурный атлас из cutout.png + psd_layers/*.png
python3 tools/build_model.py  # 2. построить меши, деформеры, параметры и физику -> moc3 + json
python3 tools/validate.py     # 3. проверить структуру модели
python3 tools/make_kit.py     # 4. сгенерировать иконку, README и архив для VTube Studio
```

Все параметры рига и физики лежат в словаре `CFG` в начале
`tools/build_model.py`:
- Амплитуды поворота головы: `yaw_scale`, `pitch_scale`, `roll_scale`
- Радиусы 3D-искажения: `r_yaw`, `r_pitch`
- Настройки физики (подвижность, задержка, ускорение) прямо в секции `physics`
- Кривые смешивания форм рта и глаз в функциях `mouth_blend()` и `eye_blend()`

### Добавление новых выражений
Все дополнительные состояния просто добавьте как PNG в `psd_layers/` и
пропишите в списки `mouth_shapes` (rig.py) / `variant_names` (build_model.py).

## Предпросмотр в браузере

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000/preview/
```

Слайдеры в панели справа — те же параметры, что передаёт VTube Studio;
есть режим следования за мышью и автоматическое «живое» движение.

> Для предпросмотра нужен **Live2D Cubism Core** (собственный файл
> `preview/lib/live2dcubismcore.min.js`, в репозитории он не хранится —
> скачивается с сайта Live2D по их лицензии). Без него каталог
> `preview/lib/` остаётся пустым, и предпросмотр не запустится;
> сам модель VTube Studio открывает без него.

## Структура репозитория

```
cutout.png / base_raw.png / geom.json   исходник персонажа и разметка лица
tools/moc3gen.py      минималистичный писатель .moc3 (Cubism 3.0), формат
                      проверен загрузкой в настоящий Cubism Core 4.2.2
tools/rig.py          подготовка текстуры: маска глаз, инпэйнт, открытый рот
tools/build_model.py  меши, деформеры, параметры, moc3 + model3/physics/cdi3
tools/validate.py     проверка комплекта (параметры, render order, sweep)
tools/render.py       офлайн-рендер PNG/ASCII (для проверки без GPU)
tools/dump_model.js   выгрузка состояния модели через Cubism Core в JSON
tools/make_kit.py     иконка + README + zip
preview/              браузерный предпросмотр (WebGL)
dist/ChibiVT/         готовый комплект
legacy/               файлы первой версии пайплайна (build_mesh/build_moc)
```

## Замечания по лицензиям

* Формат `.moc3` и загрузка модели валидировались **Cubism Core 4.2.2** —
  проприетарная библиотека Live2D. В репозитории она отсутствует.
* Текстура собрана из `cutout.png` — используйте её в рамках прав на
  исходное изображение.
