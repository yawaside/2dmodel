# Live2D-модель для VTube Studio (готова к использованию)

## Новое: интерактивная сцена «как в VTube Studio»

Добавлен просмотрщик **`/vts/`** — живая модель целиком (голова + корпус) с
трекингом, морганием, липсинком, физикой и дыханием. Это не скриншот и не
видео: сцена считается в браузере той же математикой, что записана в `.moc3`.

- **Деформация**: порт `head_warp` / `body_warp` и сеточных деформеров
  `DHead` 6×6 / `DBody` 5×5 из `tools/build_model.py` — поворот, наклон, крен
  головы, следование корпуса, дыхание (`vts/model.js`).
- **Лицо**: альфа-стек тайлов рта и глаз — `mouth_blend` / `eye_blend` /
  `stack_opa` из `storyboard/blend.js` (тот же файл, что проверяется тестом на
  совпадение с Python-моделью).
- **Движение**: курсор вместо камеры (X ±20°, Y ±12°, Z ±8° — как OUT-значения
  трекинга), idle-анимация, авто-моргание с двойными морганиями, липсинк с
  **микрофона** (Web Audio RMS, как в VTube Studio) или имитация речи,
  физика `physics3.json` (пружины с теми же scale/weight/delay).
- **VTube Studio в деталях**: ползунки всех 13 `Param*` с теми же диапазонами,
  что в `ChibiVT.cdi3.json`, группы `EyeBlink` / `LipSync` / `Breath`,
  экспрессии и жесты на клавишах `1…6`, `B`, `R`, фон сцены (прозрачный /
  тёмный / зелёный OBS / стрим), каркас модели, экспорт кадра в PNG и JSON позы.
- Cubism Core не нужен. Ассеты (`vts/pack/`) — кропы `cutout.png` и тайлы
  атласа модели, из которого собран `.moc3`.

Открыть: `python3 tools/serve.py . 8000` → `http://localhost:8000/vts/`.

```bash
python3 tools/rig.py                     # атлас модели (если ещё не собран)
python3 tools/build_vts_demo.py          # ассеты сцены -> vts/pack/
python3 -m unittest discover -s tests    # 36 проверок, вкл. JS↔Python деформацию
node tests/vts_smoke.cjs                 # страница поднимается и рисует (без браузера)
python3 tools/serve.py . 8000            # /vts/
```

### Что попутно исправлено в модели

При портировании деформации нашёлся дефект рига: нейтральный ключ деформера
головы **не был тождественным**. В `head_warp()` косинус широты ограничивался
снизу (`ca = max(cos(a), 0.25)`) уже после `asin`, поэтому при нулевом тангаже
множитель `cos(a)/ca` был меньше единицы и верх головы (примерно `y < 159`,
там где `|y − 420| > r_pitch`) стягивался к центру — макушка «защипывалась»
в складку уже в покое. Ограничение перенесено на саму широту
(`|v| ≤ sin(acos 0.25)`), теперь покой — точная единица, а полюс по-прежнему
защищён. Модель пересобрана (`dist/ChibiVT/ChibiVT.moc3` и ZIP комплекта),
регрессия ловится тестом `test_neutral_keyform_is_identity`.

## Новое: раскадровка глаз и рта для липсинка

Добавлен пакет **face storyboard** — нарисованные кадры глаз и рта, шкалы
параметров и живой интерактивный просмотрщик. Существующая модель `.moc3`
не менялась: пакет собран из **тех же тайлов текстурного атласа**, которыми
рисуется модель, поэтому каждый кадр раскадровки пиксель-в-пиксель совпадает
с тем, что рендерит Live2D.

- 6 кадров рта (липсинк: закрыт → слегка → полуоткрыт → «А» + улыбка/ухмылка)
  и 5 состояний глаз (моргание, улыбка, прищур) с зонами hold/transition.
- Листы раскадровки со шкалами `ParamMouthOpenY` / `ParamMouthForm` /
  `ParamEyeLOpen·R` / `ParamEyeSmileL·R`, кадры на голове, спрайт-листы.
- Живые GIF: липсинк 0→1→0, цикл моргания, улыбка ↔ ухмылка — **реальный
  блендинг модели**, а не коллаж.
- Интерактивный просмотрщик **`/storyboard/`**: ползунки тех же параметров,
  что и в VTube Studio; блендинг в браузере — точный порт математики `.moc3`
  (сверяется юнит-тестом JS ↔ Python). Cubism Core не требуется.
- CSV + machine-readable `manifest.json` (все зоны переходов), PSD со слоем
  на каждый кадр, ZIP всего пакета.

Готовый архив: [`storyboard/pack/ChibiVT_face_storyboard.zip`](storyboard/pack/ChibiVT_face_storyboard.zip).
[Лист рта](storyboard/pack/boards/mouth_board.png) · [лист глаз](storyboard/pack/boards/eye_board.png) ·
[подробности](face_storyboard/README.md).

```bash
pip install -r requirements-turnaround.txt
python3 tools/rig.py                        # атлас модели (если ещё не собран)
python3 tools/build_face_storyboard.py --psd   # пакет раскадровки
python3 -m unittest discover -s tests -v    # проверки, вкл. JS↔Python блендинг
python3 tools/serve.py . 8000               # /storyboard/ — интерактивный просмотр
```

## Ранее: ракурсы полного роста и раскадровка

Добавлен самостоятельный **пакет референсов для подготовки Live2D** — существующая модель `.moc3` не менялась.

- 8 ракурсов полного роста с шагом 45°: спереди, сзади, профили и промежуточные ¾.
- 9 референсов головы с целевыми ключами X/Y, прозрачные PNG полного роста, спрайт-лист, GIF, PDF, CSV и JSON.
- PSD с отдельным слоем на каждый **целый референсный кадр**, не с нарезанными частями тела.
- Новый просмотрщик **`/turnaround/`**: покадровое воспроизведение, предыдущий кадр-подложка, скачивание, локальный чек-лист. **Cubism Core не требуется.** Корень сайта открывает этот просмотрщик; прежний остаётся на `/preview/`.

**Ограничения:** задняя и нижняя части — AI-предложение дизайна по обрезанному фронтальному исходнику. Кадры 45°, 135°, 270° — явно отмеченные зеркальные черновики. Нужно согласовать пропорции, микрофон, платок и подсумки. Это не точная 3D-реконструкция и не готовый 360° риг; X/Y головы — приблизительные целевые ключи.

Готовый архив: [`turnaround/pack/ChibiVT_turnaround_pack.zip`](turnaround/pack/ChibiVT_turnaround_pack.zip). [Лист ракурсов](turnaround/pack/turnaround_board.png) · [Подробная инструкция и структура слоёв](turnaround/README.md).

```bash
pip install -r requirements-turnaround.txt
python3 tools/build_turnaround.py --psd  # офлайн, по сохранённым AI-листам
python3 -m unittest discover -s tests -v
python3 tools/serve.py . 8000           # /turnaround/
```

## 🆕 Улучшенная физика рта и глаз (v2)

Из PSD-раскадровки (`chibi_soldier_rig.psd`) и отдельных слоев в `psd_layers/`
собирается полноценная модель Live2D Cubism 3.0 (`.moc3`), которую VTube Studio
открывает как обычную модель: **идеальный лип-синк по гласным A/E/I/O/U,
натуральное моргание с физикой, улыбка, прищур, анимация дыхания** — всё работает
сразу после Auto-Setup.

## Готовый комплект

```
dist/ChibiVT/                     <- эту папку целиком скопировать в VTube Studio
├── ChibiVT.model3.json           <- главный файл модели
├── ChibiVT.moc3                  <- геометрия, деформеры, параметры (~1 МБ)
├── ChibiVT.physics3.json         <- идеальная физика: тело, глаза, рот, дыхание
├── ChibiVT.cdi3.json             <- служебное (VTube Studio не нужно)
├── icon.png                      <- иконка в списке моделей
├── README.txt                    <- инструкция (рус.)
├── README.en.txt
└── textures/texture_00.png       <- атлас 2048×2048 со всеми выражениями лица
```

Архив для скачивания: **`dist/ChibiVT_vtube_studio.zip`**.

### Установка

1. Скопируйте **всю папку** `ChibiVT` (не отдельные файлы) в папку
   `Live2DModels` вашего VTube Studio. Её можно открыть кнопкой
   *Open Data Folder* в настройках VTube Studio (Steam-версия).
2. Запустите VTube Studio — модель появится в списке.
3. Согласитесь на **Auto-Setup** — VTube Studio сам привяжет трекинг к
   стандартным параметрам.

## Что анимировано

| Параметр | Диапазон | Что делает |
|---|---|---|
| `ParamAngleX` / `Y` / `Z` | −30…30 | поворот головы влево/вправо, вверх/вниз, наклон (3D-эффект на цилиндре/сфере) |
| `ParamBodyAngleX` / `Y` / `Z` | −10…10 | наклон и поворот корпуса с пружинной физикой (догоняет голову) |
| `ParamEyeLOpen` / `ParamEyeROpen` | 0…1 | плавное моргание по нарисованным кадрам: закрыт → прищур → нейтраль; в покое — спокойный нейтральный взгляд |
| `ParamEyeSmileL` / `ParamEyeSmileR` | 0…1 | улыбка/прищур глаз, с автоматической физикой при повороте головы вверх |
| `ParamMouthOpenY` | 0…1 | лип-синк по монотонной цепочке: закрыт → слегка → полуоткрыт → А (широко открыт) — плавно, без скачков форм |
| `ParamMouthForm` | −1…1 | форма рта: ухмылка (−1) ← нейтраль (0) → улыбка (1), с физикой перелёта при лип-синке |
| `ParamBreath` | 0…1 | естественное дыхание (покачивание головы и плеч), генерируется физическим движком |

## Особенности идеальной физики

### Рот (лип-синк)
- **6 нарисованных кадров** вместо восьми: закрытый, слегка приоткрытый,
  полуоткрытый, А (широко открыт), улыбка, ухмылка — рот открывается одной
  монотонной цепочкой, без прыжков между формами (O и оскал убраны)
- **Паузы с короткими переходами**: каждый кадр «держится» на своей
  диапазоне (закрыт 0–0.12, слегка 0.20–0.38, полупр. 0.47–0.66,
  А 0.76–1.0), переходы занимают всего 8–10% шкалы (0.12–0.20,
  0.38–0.47, 0.66–0.76) — предыдущий кадр успевает исчезнуть до
  появления нового, нет эффекта «двойного рта»
- В любой момент смешиваются **не более двух** кадров — нет «призраков»
  и полупрозрачных слоёв друг на друге; в 78 точках из 101 на шкале
  виден ровно один кадр
- Служебные «серые кавычки» (артефакт экспорта PSD в углах каждого слоя рта
  и глаз) вырезаются при сборке текстуры (`rig.py`, `clean_layer`) — с защитной
  маской линии рта, чтобы контур оставался гладким и без пикселизации
- Небольшой «перелёт» (overshoot) при быстром открытии/закрытии — мягче
  прежнего, чтобы форма рта не дёргалась при лип-синке
- Нет артефактов растягивания: все формы нарисованы вручную в PSD

### Глаза
- 5 состояний на каждый глаз: нейтраль, полуоткрыт, моргание, улыбка, прищур.
  «Широко раскрытый» кадр убран: при полном открытии остаётся спокойный
  нейтральный взгляд
- Плавная интерполяция: в каждый момент максимум два кадра, без рывков
- Естественные микродвижения и реакция на повороты головы (смягчены)
- При взгляде вверх глаза автоматически прищуриваются
- Нет «призраков» и растянутых текстур — все веки нарисованы

### Общая физика
- Корпус догоняет поворот головы с естественной задержкой и демпфированием, как у туловища
- Постоянная лёгкая анимация дыхания (грудь поднимается, голова слегка покачивается)
- При улыбке автоматически срабатывают улыбающиеся глаза, даже если трекинг видит только рот

## Как пересобрать / подкрутить

```bash
pip install numpy pillow
python3 tools/rig.py          # 1. собрать текстурный атлас из cutout.png + psd_layers/*.png
python3 tools/build_model.py  # 2. построить меши, деформеры, параметры и физику -> moc3 + json
python3 tools/validate.py     # 3. проверить структуру модели
python3 tools/make_kit.py     # 4. сгенерировать иконку, README и архив для VTube Studio
```

Все параметры рига и физики лежат в словаре `CFG` в начале
`tools/build_model.py`:
- Амплитуды поворота головы: `yaw_scale`, `pitch_scale`, `roll_scale`
- Радиусы 3D-искажения: `r_yaw`, `r_pitch`
- Настройки физики (подвижность, задержка, ускорение) прямо в секции `physics`
- Кривые смешивания форм рта и глаз в функциях `mouth_blend()` и `eye_blend()`

### Добавление новых выражений
Все дополнительные состояния просто добавьте как PNG в `psd_layers/` и
пропишите в списки `mouth_shapes` (rig.py) / `variant_names` (build_model.py).

## Предпросмотр в браузере

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# открыть http://localhost:8000/preview/
```

Слайдеры в панели справа — те же параметры, что передаёт VTube Studio;
есть режим следования за мышью и автоматическое «живое» движение.

> Для предпросмотра нужен **Live2D Cubism Core** (собственный файл
> `preview/lib/live2dcubismcore.min.js`, в репозитории он не хранится —
> скачивается с сайта Live2D по их лицензии). Без него каталог
> `preview/lib/` остаётся пустым, и предпросмотр не запустится;
> сам модель VTube Studio открывает без него.

## Замечания по лицензиям

* Формат `.moc3` и загрузка модели валидировались **Cubism Core 4.2.2** —

* Текстура собрана из `cutout.png` — используйте её в рамках прав на
  исходное изображение.
