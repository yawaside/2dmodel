# Просмотрщик «как в VTube Studio» · `/vts/`

Живая сцена: модель целиком (голова + корпус) двигается, моргает, говорит и
дышит — той математикой, которая записана в `ChibiVT.moc3`. Cubism Core не
нужен: страница считает деформацию и блендинг сама, в WebGL.

Открыть:

```bash
python3 tools/serve.py . 8000      # затем http://localhost:8000/vts/
```

`file://` не подойдёт: страница читает `pack/manifest.json` через `fetch`.

## Что на странице

| Возможность | Чем управляется |
|---|---|
| Трекинг | курсор вместо камеры: X ±20°, Y ±12°, Z ±8° (как OUT-значения трекинга в VTS) |
| Idle-движение | плавное «дыхание» позы, когда трекинг выключен |
| Моргание | интервал 1.6–6 с, одиночные и двойные моргания (как авто-моргание VTS) |
| Липсинк с микрофона | Web Audio, RMS-громкость → `ParamMouthOpenY` (звук не записывается) |
| Речь (симуляция) | слоги со случайной длительностью — тот же `ParamMouthOpenY` |
| Физика | пружины по `ChibiVT.physics3.json`: корпус догоняет голову, прищур от наклона, довод формы рта |
| Дыхание | `ParamBreath`, ≈4.2 с на вдох-выдох |
| Экспрессии | `1…6` — нейтраль, улыбка, ухмылка, открытый рот, удивление, сонный |
| Жесты | моргнуть (`B`), кивок, покачать головой; `R` — сброс позы |
| Сцена | фон: прозрачный / тёмный / зелёный OBS / стрим; размер, позиция, поворот — как в VTS |
| Экспорт | PNG кадра (с фоном) и JSON всех параметров текущей позы |

Ползунки в разделе «Параметры VTube Studio» повторяют `ChibiVT.cdi3.json`:
те же идентификаторы и диапазоны. Параметры, которыми управляет источник
(трекер, физика, микрофон), помечены — в VTube Studio они ведут себя так же и
перезаписывают ручное значение.

## Как это устроено

```
cutout.png ──tools/rig.py──► атлас модели ──┐
                                            ├─ tools/build_vts_demo.py ─► vts/pack/
                     dist/ChibiVT/*.moc3 ───┘   (кропы головы и корпуса,
                                                 тайлы рта и глаз, manifest.json)

vts/index.html + style.css + app.js + model.js ─► сцена в браузере
```

- `model.js` — порт `head_warp` / `body_warp` и сеточных деформеров
  (`DHead` 6×6, `DBody` 5×5) из `tools/build_model.py`; смещения узлов
  интерполируются билинейно, как это делает Cubism Core при обновлении модели.
- `storyboard/blend.js` — `mouth_blend` / `eye_blend` / `stack_opa` (общий файл
  с раскадровкой лица).
- Рендер: две сетки (голова, корпус) по ~10 px, вершины пересчитываются каждый
  кадр; лицо композитится в offscreen-канвас той же альфа-стопкой, что в
  `.moc3`, и уезжает в текстуру только когда параметры лица изменились.

## Точность (и где она не абсолютна)

| Часть | Точность |
|---|---|
| Блендинг рта и глаз | точный порт, сверяется тестом JS ↔ Python |
| Деформация головы и корпуса | точный порт формул и сеток деформеров |
| Моргание, липсинк, экспрессии | тайминги и кривые — типовые для VTS |
| `physics3.json` | приблизительно: Cubism Physics считает свои вершины, здесь пружины с теми же коэффициентами |
| Трекинг лица | курсор вместо камеры |

Максимальный тангаж (±30°) стягивает макушку: цилиндр тангажа
(`r_pitch = 270` при высоте головы ~595 px) заканчивается раньше, чем верх
головы. Покой при этом точный (см. `tests/test_vts.py`); если нужен запас по
тангажу — увеличьте `r_pitch` в `tools/build_model.py` и пересоберите модель.

## Проверки

```bash
python3 -m unittest discover -s tests    # tests/test_vts.py: паритет JS↔Python, структура пакета, свойства сетки
node tests/vts_smoke.cjs                 # страница поднимается и рисует (DOM/WebGL-заглушки)
```

## Пересборка ассетов

```bash
python3 tools/rig.py              # атлас (если build/ пуст)
python3 tools/build_vts_demo.py   # vts/pack: кропы, тайлы, manifest.json
```
